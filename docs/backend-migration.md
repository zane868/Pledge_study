# 后端迁移与 PRD 功能对照

2026-11-03，从 `ProjectBreakdown-Pledge/pledge-backend` 迁入 Go 后端，保留 API、模型、
校验器、调度服务及工具结构。来源提交和原始 Go 文件哈希保存在
`pledge-backend/reference/source-manifest.json`。

## 本次适配

| PRD 范围 | 已迁入或调整 |
|---|---|
| 12.1 后台登录 | 环境配置密码；HS256 校验；JWT 与 Redis 过期时间一致；会话失效及退出；不记录登录密码 |

| 13.2 标识、金额和接口 | 池记录增加池合约；查询按 chainId/合约/池编号隔离；区分 poolIndex 和 displayPoolId；金额保持原始十进制字符串 |
| 13.3 数据同步 | 读取确认后的同一区块；校验 RPC chainId；读取后复核区块哈希；基础数据、分配数据和水位在同一 SQL 事务提交 |
| 13.3 异常和缓存 | 不再清空 Redis；写库失败回滚，缓存不推进；分配数据独立更新；失败与过期状态可见；未就绪市场拒绝伪空结果 |
| 13.4 现有接口 | 迁入池、代币、搜索、多签配置、登录和退出路由；移除 BSC 56/97 的固定链限制；参数绑定错误不再直接类型断言导致 panic |
| 13.4 查询正确性 | 搜索使用参数化条件；分页分配数据按完整池标识关联；检测查询中快照变化；分页限制为最多 100 条 |
| 13.5 ABI 和部署 | 根据当前 Foundry 产物重建 Pool、Oracle、DebtToken、多签绑定；嵌入已验证的 Sepolia 部署信息；使用 go-ethereum/abigen 1.17.8 |
| 运行配置 | Go 1.25+；MySQL、Redis；构建与启动 Makefile、Dockerfile、Compose；静态图片随二进制嵌入；日志输出至标准流 |

## 验证结果与限制

- `go build ./...`、`CGO_ENABLED=0 go build ./...` 和 `go vet ./...` 通过。
- `go test ./...` 通过，包含三个集成回归用例：分配更新与多池隔离、失败回滚与缓存推进、后台鉴权与未同步市场。
- 测试使用 SQLite 和进程内 Redis，验证事务、查询和 HTTP 行为；不等同于 MySQL 方言和独立 Redis 的服务级验收。
- 实际 Sepolia RPC 只读验证成功：链 ID 11155111，主池 `0x91A621F4D3f3e72b8bbD53D7387a914b9Ef29E82`，读取一个池及 ETH、测试稳定币、SP、JP 四份元数据。
- 本地没有 Docker、MySQL、Redis 服务可执行文件，Compose 镜像构建未实测。
- 后续已在 `43.160.212.151` 的实际 MySQL/独立 Redis 环境完成 API 和同步进程联调，详见 [服务器部署说明](backend-server-deployment.md)。Compose 镜像构建仍未实测。
