## 功能与验证映射

| PRD 范围 | 本次基线与验证 |
|---|---|
| 4、6 资产、参数与凭证 | 创建 ETH/稳定币池；每池独立 SP/JP；授权池为 minter |
| 5 状态机 | MATCH → EXECUTION / UNDONE；EXECUTION → FINISH / LIQUIDATION |
| 7 入金、匹配与退款 | 额度、最小金额、截止边界、双方不平衡、多人比例和募集失败退出 |
| 8 领取与权益转移 | SP、借款及 JP；重复领取拒绝；转让与分次赎回；终态迟领 |
| 9 结算、利息与费用 | 真实本地 DEX；365 天和 30 天计息；实际产出费用；剩余 ETH 分配 |
| 10 风险与暂停 | 阈值查询、现有清算、暂停恢复、失败不改变状态与余额 |
| 12 权限 | 正式 2/2 多签的申请、签署、撤销；未授权价格与铸销操作拒绝 |
| 13 构建与部署 | 四地址构造、当前 ABI、本地依赖与地址清单 |

测试中的清算行为是对原实现的核实：即使风险查询为 false，获授权调用者仍可清算，
并按完整约定期限计息。该测试通过不代表清算交付要求已经完善。

2026-11-03 升级后验证：Foundry 编译成功；20 个 Solidity 测试全部通过，
其中算术模糊测试执行 256 轮。测试覆盖正式合约及实际本地 DEX。

## 后续合约工作

以下由 PRD 已明确区分为现状、交付要求或待决策项。本次编译器升级保留这些业务规则和未决项。

| 事项 | 现有实现与后续工作 | PRD 依据 |
|---|---|---|
| 授权范围 | 按申请账户与目标合约授权，可复用且无到期限制；确认是否改为绑定完整交易并消耗审批，处理 owner 变更后的旧签署 | 12.2、15.1.3 |
| 清算条件与计息 | 入口未强制阈值；保留完整约定期限计息；明确允许的触发条件与计息政策 | 10.2、10.3 |
| 不足额资产退出 | 超预算兑换可能回滚；需要明确有限抵押物处置、损失分配和终态退出 | 9.5.3、10.3.4 |
| 报价与路由授权 | 最小兑换产出为零、执行时生成 deadline、输出代币也无限授权；落实最大支出、最小产出、有效期及旧授权处理 | 9.3.3、14.1.3 |
| 池级预算与凭证隔离 | 资产在同一合约，建池未完整校验凭证唯一性；补充参数、池级可支出预算、累计分配和凭证不变量验证 | 4.3、6.2、15.1.1 |
| 价格数据 | 零价、负值、陈旧轮次与精度需校验；批量 setPrices 当前按数组索引写入而非 assets[i]，需修复并回归 | 7.2、10.1、12.3.3 |
| 全局费用变更 | 存续池结算读取当前费用；决定是否冻结，并限定参数合法范围 | 6.3、9.3.2 |
| 迟到匹配与零成交 | 当前允许到期后首次匹配；双边非零但整数结果为零需要明确失败处理 | 5.3、7.2.3 |
| ETH 支付与非标准代币 | transfer 对部分合约钱包不兼容；ERC20 入金按请求量记账；补充兼容及重入测试 | 15.1.2 |
| 舍入与零兑付 | 固定分母、逐步向下取整；明确零兑付保护及余量归属 | 4.3.4、8.3、9.4.2 |

后续按确定的规则逐项修改正式合约，并为每项资金或权限变化增加回归用例。
