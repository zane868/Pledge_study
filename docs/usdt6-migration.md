# ETH / USDT 六位精度实现

2026-11-03，按确认的产品规则实施。

## 数值口径

| 数量 | 原始单位 |
|---|---|
| ETH 抵押、退款、JP 最终兑付 | 10^18 |
| USDT 入金、匹配本金、借款、退款、本息、费用和 SP 最终兑付 | 10^6 |
| SP / JP 凭证 | 10^18 |
| 利率、抵押率、平台费率 | 10^8 |
| 每整枚资产的预言机价格 | 10^8 |

`lendScale[poolIndex] = 10^(18 - USDT.decimals()) = 10^12`。
实际成交本金 M 使用 USDT 原始单位，SP 固定分母为 M × 10^12；
JP 固定分母为 floor(M × 10^12 × martgageRate / 10^8)。
铸造和赎回共用固定分母，转账、销毁和迟领不改变分母。

匹配时先使用 18 位统一计算口径估值，再转换回 USDT 最小单位。
可借本金向下取整，反算匹配 ETH 时向上取整，计算采用 Math.mulDiv。
例如 1 ETH、ETH 价格 2000 USDT、抵押率 200%，可成交 1000 USDT，
链上记录为 `1000000000`，SP 为 `1000 × 10^18`，JP 为 `2000 × 10^18`。
JP 数量表示份额基数，不是固定 ETH 数量。

## 合约修改

- 正式池读取并校验借款资产 decimals，支持 6/18 位；同一池合约限定单一借款资产及原生 ETH 抵押。
- 池保留 USDT 原始金额记账；匹配、风险估值、SP/JP 铸造及赎回显式转换单位。
- SP 极小额销毁如果无法产生至少一个 USDT 最小单位，则整笔回滚，保留凭证。
- 兑换使用原始单位，输出 USDT 不再获得无限授权；必要输入授权使用 forceApprove。
- 预言机按价格源 decimals() 归一化为每整枚资产的 10^8 报价，不再混入代币 decimals。
- 修复 setPrices 的资产键映射，拒绝非正价格及无效价格轮次；旧 setDecimals 入口仅允许保持固定精度。
- 新增 TestUSDT：6 位演示资产，明确不是发行方官方 USDT。
- SP/JP 继续保持 18 位，不修改 DebtToken 的 decimals。

## 验证

Amsterdam 运行时下 26 个 Foundry 测试通过，包括：六位资产的匹配、两端退款、
18 位凭证、完整/分次赎回、零兑付保护、费用、迟领、风险估值及清算。
同时覆盖外部价格源精度、批量价格资产键、原有十八位资产回归和两组各 256 轮模糊测试。

本次未改变完整约定期限计息、清算入口权限或不足额退出政策；未定义价格源最大时效。
尚未解决的 PRD 交付缺口继续保留，不能把本次精度适配视为全部资金规则验收完成。

## 全新项目基线

按用户确认，本项目作为全新 ETH/USDT 项目开发，不再设计 BUSD 兼容、旧池迁移、旧地址注册或数据切换流程。
活动部署以 `pledgev2/networks/sepolia.json` 为唯一配置来源。后端直接使用当前 USDT 六位精度和新 ABI。
之前的十八位算例只作为数学回归测试，不作为产品支持的借款资产。

当前已部署的 USDT 六位测试服务继续运行，不为清理历史说明再创建一套部署。
